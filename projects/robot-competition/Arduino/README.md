# Arduino Code

This folder contains the Arduino code used for the robot project.

## Files Included
- [Final Competition Code](MAE3783RobotFinal.ino)  
  Main Arduino code used during the robot competition.

- [QTI Threshold Test Code](QTIThresholdTest.ino)  
  Test code used to measure and tune the QTI sensor threshold values for detecting the black border.

## Purpose

The Arduino code controls the robot’s driving behavior, sensor readings, and competition strategy. The QTI test code was used during calibration to make sure the sensors could reliably distinguish between the black border and the rest of the board.
