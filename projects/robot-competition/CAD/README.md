# CAD Files

This folder contains the CAD files for the robot design.

## Files Included

- [Full Robot Assembly](boe-bot.SLDASM)  
  SolidWorks assembly file showing how the main robot components fit together.

- [Chassis STEP File](Part1%5Eboe-bot.STE)  
  Exported chassis model for easier viewing and sharing across CAD programs.

## Purpose

The CAD files show the physical design of the robot, including the outer shell/chassis used to protect the wheels, guide cubes toward the robot body, and keep the robot low and stable during competition.
