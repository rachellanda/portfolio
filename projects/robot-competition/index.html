MAE 3780 Robot Competition Robot

Project Overview

This project was completed for a robotics competition in MAE 3780. The robot was designed to move around the competition board, avoid the black border using QTI sensors, and interact with cubes using a low outer chassis.

Robot Design

The robot used a large outer shell close to 8 inches by 8 inches. The chassis helped protect the wheels from cubes and created space for cubes to move into the robot body. The low profile also helped the robot push other robots effectively during the competition.

Sensors and Controls

Two QTI sensors were used to detect the black border of the competition board. When the robot detected the border, it turned away from the edge and continued moving around the board. The Arduino code controlled the driving behavior, sensor readings, and turning logic.

On competition day, the robot finished with 3 wins, 3 losses, and 1 tie.
